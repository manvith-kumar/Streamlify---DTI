# 🌟 Streamlify – Career Guidance Platform 🚀

Welcome to **Streamlify**, your intelligent career guidance companion! 🎓  
This platform is designed to help students explore various **job roles** available under each **engineering (B.Tech)**, **pharmacy (B.Pharm)** branch and some more branches. With skill-based suggestions, streamlined navigation, and an intuitive interface, Streamlify empowers students to make informed career choices with confidence. 💼📚

---

## 📌 Features

🔹 **Branch-Wise Navigation**  
Easily explore all major branches including CSE, IT, AI/ML, ECE, EEE, MECH, CIVIL, and more!  
Also includes B.Pharm-specific streams like Pharmaceutical Analysis.  

🔹 **Job Role Explorer**  
Each branch page lists multiple job roles along with descriptions and required skills for that role.  

🔹 **Skill Insights**  
Students can understand the skills needed for each job and start working toward their goals early.  

🔹 **Color-Coded Roles**  
Each job role is visually distinguished using a unique color palette, enhancing user experience and recall.

🔹 **Mobile-Friendly Design**  
The site is responsive and designed for seamless use on desktops, tablets, and mobile devices.

🔹 **Centralized Navigation**  
Use the home page to choose your stream, view testimonials, and navigate across branches easily.
